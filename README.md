# Gallup CliftonStrengths Assessment App

Веб-приложение (с адаптацией под смартфоны и Telegram Mini Apps) для тестирования линейных сотрудников по методологии Gallup CliftonStrengths.

## Стек технологий
- **Фреймворк:** [Next.js 15 (App Router)](https://nextjs.org/) + React 19 + TypeScript
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/) (mobile-first UI)
- **База данных:** SQLite + [Prisma ORM](https://www.prisma.io/)
- **Иконки и эффекты:** Lucide React, Canvas Confetti

## Особенности и механика
1. **34 таланта в 4 доменах:**
   - **Executing (Исполнение):** 9 талантов
   - **Influencing (Влияние):** 8 талантов
   - **Relationship Building (Отношения):** 9 талантов
   - **Strategic Thinking (Мышление):** 8 талантов
2. **Банк из 68 вопросов:**
   - Каждый талант встречается ровно 4 раза в перекрестных парах из разных доменов ($68 \times 2 = 136$ слотов).
   - Вопросы адаптированы под контекст линейного персонала (продажи, работа в смене, касса, стресс, клиенты).
3. **Scoring Engine:**
   - Шкала $-2 \dots +2$ (+2.0, +1.0, нейтрально +0.3, таймаут 0).
   - Скоростной бонус $\times 1.15$ при инстинктивном ответе быстрее 8 секунд.
   - Двухуровневый Tie-Breaker для строгого ранжирования с 1 по 34 место.
4. **Интерфейс:**
   - `/` — Экран старта, онбординг, восстановление сессии.
   - `/test/[id]` — Прохождение теста с анимированным 20-секундным таймером и эргономичными кнопками.
   - `/results/[id]` — Профиль сотрудника: Доминирующий домен, Топ-5 талантов, Слепая зона (30–34) и полный список всех 34 талантов.
   - `/admin` — Дашборд руководителя: аналитика, карточка сотрудника с инструкциями по мотивации и постановке задач, Командная матрица (Team Grid).

## Установка и запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Инициализация базы данных и заполнение вопросами/талантами
npm run db:push
npm run db:seed

# 3. Запуск в режиме разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
